# AI-Powered Customer Support Intelligence Platform

## Overview

An end-to-end Machine Learning and NLP platform that automates customer support operations by classifying support tickets, predicting ticket priority, estimating resolution time, and generating customer insights using Machine Learning, Deep Learning, and Transformer models.

## Features

* Ticket Type Classification using DistilBERT
* Ticket Priority Prediction
* Resolution Time Estimation
* Customer Segmentation with K-Means
* MLflow Experiment Tracking
* SHAP Model Explainability
* FastAPI Deployment
* Docker Containerization
* Interactive Dashboard (Power BI / Plotly Dash)
